# Legacy .NET compatibility guide

This page documents the preserved `DNS.Client` namespace. New applications should use
the `Ratatoskr` API shown in the repository README; ordinary legacy queries now call
the same native C core.

## High-level resolver

`LookupClient` is convenient for application code. It adds resolver options, a
concurrent TTL cache, and typed answer helpers on top of the protocol client:

```csharp
using DNS.Client;

var lookup = new LookupClient(new LookupClientOptions
{
    NameServers = new[] { NameServer.Cloudflare },
    Timeout = TimeSpan.FromSeconds(2),
    Retries = 3,
    EnableCache = true
});

var response = await lookup.QueryAsync("_sip._tcp.example.com", QuestionType.SRV);
foreach (var srv in response.Answers.SrvRecords())
    Console.WriteLine($"{srv.Target}:{srv.Port} (priority {srv.Priority})");
```

The cache key includes name, type, and class. It expires at the shortest answer TTL;
call `ClearCache()` after a configuration change or when immediate fresh data is
required.

## Compatibility

The library targets .NET Standard 2.0 and 2.1. It can be referenced by applications
whose runtime implements either standard, including .NET Framework 4.6.1+ (through
the .NET Standard 2.0 compatibility surface), .NET Core, and modern .NET releases.
The netstandard2.0 build uses the small `System.Memory` compatibility package and
does not depend on another DNS or networking package.

## Create a client

`new DnsClient()` discovers the DNS servers configured on active network interfaces.
For deterministic server selection, pass an address or a list of endpoints:

```csharp
using System.Net;
using DNS.Client;

var client = new DnsClient(new[]
{
    new IPEndPoint(IPAddress.Parse("192.0.2.53"), 53),
    new IPEndPoint(IPAddress.Parse("198.51.100.53"), 53)
})
{
    Timeout = TimeSpan.FromSeconds(3),
    Attempts = 4
};
```

`Attempts` is the total number of UDP attempts. Endpoints are selected in order and
wrapped when there are more attempts than servers.

## Query records

```csharp
DnsMessage response = await client.QueryAsync("example.com", QuestionType.MX);

foreach (DnsResourceRecord answer in response.Answers)
{
    if (answer.Data is MxRecordData mx)
        Console.WriteLine($"{mx.Preference} {mx.Exchange}");
}
```

`Query` is the synchronous equivalent. Queries use UDP under the RFC 1035 512-byte
limit and automatically repeat over TCP when a response has its truncation bit set.
Use `SendTcpAsync` when TCP is required from the outset.

All query methods accept a `CancellationToken`. `Timeout` applies to each network
operation. A timeout raises `TimeoutException`; caller cancellation raises
`OperationCanceledException`.

## Response errors

By default, responses such as `NameError` and `ServerFailure` are returned normally,
allowing the caller to inspect their authority records:

```csharp
if (response.Header.ResponseCode == DnsResponseCode.NameError)
    Console.WriteLine("The name does not exist.");
```

Set `ThrowOnResponseError` to `true` to raise `DnsResponseException` for a non-zero
response code. Malformed or mismatched packets raise `DnsProtocolException`.

## Record data

`DnsResourceRecord.Data` uses one of the following models:

| Record type | Data model |
| --- | --- |
| A | `ARecordData` |
| CNAME, MB, MD, MF, MG, MR, NS, PTR | `NameRecordData` |
| HINFO | `HInfoRecordData` |
| MINFO | `MInfoRecordData` |
| MX | `MxRecordData` |
| SOA | `SoaRecordData` |
| TXT | `TxtRecordData` |
| WKS | `WksRecordData` |
| NULL and unknown types | `RawRecordData` |

Unknown record type and class numbers are retained by their enum casts and opaque
RDATA, so an extension record can be parsed and serialized without data loss.

## Reverse lookup

```csharp
DnsMessage reverse = await client.QueryReverseAsync(IPAddress.Parse("192.0.2.10"));
```

This creates the RFC 1035 IPv4 `10.2.0.192.in-addr.arpa` PTR query. IPv6 reverse DNS
was standardized after RFC 1035 and is intentionally not generated by this helper.

## Low-level messages

Use `DnsMessage` when a standard convenience query is not sufficient:

```csharp
var message = new DnsMessage(new DnsHeader
{
    Id = 0x1234,
    OpCode = DnsOpCode.Status,
    RecursionDesired = false
});

DnsMessage result = await client.SendAsync(message);
```

`DnsMessage.ToArray()` writes wire bytes and `DnsMessage.Parse(bytes)` parses them.
Names are compressed by default. Pass `compressNames: false` when an uncompressed
message is useful for diagnostics.

Domain names use RFC master-file escapes when a label contains otherwise ambiguous
octets. For example, `host\.name.example` contains a literal dot in its first label,
and `\255.example` contains byte value 255.

## Zone transfer

```csharp
DnsMessageCollection messages = await client.TransferZoneAsync("example.com");
IEnumerable<DnsResourceRecord> records = messages.SelectMany(message => message.Answers);
```

AXFR always uses TCP and reads messages through the terminating SOA. Most public DNS
servers refuse zone transfers unless the client is authorized.
